# 基础模块：力学微实验

## 课程结构

以一个均匀受拉试件为共同对象，将基础内容重写为五个可独立返回的小实验。学生依次观察图示、改变一个条件、回答判断题，错误回答给出具体的再观察提示。

1. 建模：比较带微观晶粒示意的试件与理想连续体。保留宏观外形、尺寸及受力条件，忽略晶粒细节。
2. 内力：假想切开试件，隔离左段。在没有分布轴向荷载时，N = F，截面位置变化不会改变 N。
3. 应力：同一拉力下，固定100mm²参考截面与可调截面并排比较。正方形边长按面积的平方根缩放；橙色⊙表示垂直截面向外的法向力，避免画成截面内的横向力。
4. 应变：对照整体平移与拉伸，直接从两端相对位移求 ΔL 和 ε。画面中的位移放大100倍，数值保持真实量纲。
5. 材料：用钢、铝、黄铜的教学代表参数说明 E 与 ν；区分刚度与强度，不引入未经验证的塑性曲线。

## 独立实现

本模块的教学文案、判断题、自绘SVG图示、试件标记、复位与前进图标、样式和交互状态均重新编写。入口为 `foundation/FoundationLesson.tsx`，计算逻辑在 `foundation/model.ts`，图形在 `foundation/diagrams.tsx`。

基础模块使用 `h5/Standalone.tsx` 启动，不导入旧基础组件、通用实验外壳、通用图标库、理论侧栏或原来的主题变量。其他模块仍通过原有H5入口构建。本模块的固定路径继续为 `fundamentals/`。

## 视觉规范

- 页面背景：纯白 `#FFFFFF`。
- 正文与主控件：深墨绿 `#153B35`。
- 次要文字：`#6B7C75`；分隔线：`#CBD3CF`。
- 图示底色：`#F3F6F1`；外力与重试提示：`#D86A3B`。
- 手机：单列、五步进度线、核心图示、紧邻的实验控件、判断题与下一步按钮。
- 桌面：图示与控件并列，判断题横排；保持同一阅读顺序。
- 图标：试件截面轮廓、开放圆弧复位、细线方向箭头及带明确符号的选择圆圈。均为可编辑SVG。

概念参考由内置 Image Gen 生成，手机与应力状态分别保存在本目录。科学图示在实现中依据模型精确绘制；截面内力、正应力、几何应变和线弹性应变的结果由同一纯计算函数提供。

完整生成提示与图示修订记录见 [Image Gen提示](imagegen-prompts.md)。

## 数值与边界

输入采用kN、mm、mm²、GPa；σ以MPa、ε以无量纲值计算，界面将应变明确换算为百分数。界面默认F=6kN、A=200mm²、L₀=200mm、E=200GPa，对应σ=30MPa、ε=0.00015、ΔL=0.03mm。

应变步骤是两端位移测量；材料步骤另外采用线弹性本构估计变形。模型允许比较刚体平移与相对位移，不将每一个点的位移直接当作应变。显示材料参数属于代表值，不等同于某一材料批次的检验数据。

15项新增回归覆盖单位换算、截面位置不变性、面积反比、平移零应变、伸长与应变、弹性模量反比、泊松比零横向应变、零载荷及无效参数。基础ZIP仅含根目录index.html，脚本及样式全部内嵌。
