# 基础模块：完整内容与实验台设计

## 当前布局修订

沿用现有配色、字号与 SVG，针对右侧阅读区过长的问题调整结构：上方为并列的图形与操作区，四个假设使用两列选择，知识要点收在操作区底部；随堂题独立为下方横排，反馈显示在选项下方。解除原来 650px 的画布最小高度，并收紧模型 SVG 的可视范围，完整保留箭头、尺寸及说明。手机端七个章节入口使用四列两行展示，知识要点采用名称与解释对齐的列表，随堂题选项单列排列。本文原始概念图保留为视觉风格参考，布局以本节修订为准。

## 内容边界

参考原项目基础模块的知识范围，重新编写文案与图示：连续性、均匀性、各向同性、小变形；截面法；正应力与切应力；位移、线应变与切应变；胡克定律、泊松效应和剪切模量；四类基本变形；工程应力与真应力。保留原有五个微实验，新增基本变形和应力对照，七节均有知识要点与判断题。

简单剪切使用 γ = δ/H，并显示实际角度 atan(δ/H)，不把角度与位移梯度混为一谈。应力对照单独使用均匀拉伸、体积不变的几何教学模型，不将大应变当成线弹性材料实验；固定拉力下的曲线只是应力定义对照，并非材料应力应变本构曲线。颈缩后不能由整体伸长换算局部真应力。

## 视觉规范

以 desktop-concept.png 与 mobile-concept.png 为完整界面参考。背景 #f7f9fc，白色阅读面板，深蓝实验画布 #101e35；交互蓝 #0867f9，图形青 #58d9ef，外力琥珀 #ffc36c。桌面头部品牌、七个章节和重置同一横排，实验图左侧占约 62%，右侧阅读与控制占约 38%。手机头部与可横向滚动的章节分行，图形、阅读控制与下一节依次排列。

品牌使用已有独立项目试件矢量标记，不更换为概念图意外生成的立方体。全部实验图为可操作的 SVG，二维图和可计算几何模型优先于概念图的光影质感；不将生成图片当网页背景或交互替代。

字体：系统中文字体；品牌 22/18px，内容标题 24/20px，正文 15/14px，公式 22/20px，知识题目 17/16px，图注 12px。按概念的容器结构与信息顺序实现；不添加巨大头图标题。圆角 12px，面板边线 #dbe5ef，控件最小点击高度 44px。图形采用网格、金属渐变、青色轮廓、虚实对照和少量发光点；外力箭头与内力颜色区分。

动画：页面直接清晰显示，变形演示由学生主动播放，可暂停；遵循减少动态偏好，未播放时滑块可逐步操作。章节切换保持键盘操作，焦点随章节进入可视范围。屏幕阅读器可读图形说明与当前结果，判断反馈使用 status。

## 有意差异

概念图的坐标小轴与照片级内部网络简化为真实 SVG 网格与试件晶粒图，避免坐标标注错误；每个假设提供实际例外说明。手机截图中状态栏与设备外框不属于网页。新增章节沿用同一实验画布、控制面板、知识带与判断题组件。所有地址不变，原项目保持只读。

## 实现对照

逐项对照桌面与手机概念及浏览器截图：

- 容器：桌面左深色画布、右白色阅读面板；手机图形在上、阅读在下，保持参考的信息顺序。
- 色彩：深蓝网格、青色轮廓、琥珀受力箭头与蓝色选择态均对应概念，知识阅读区保持白色。

- 控件：四个假设桌面纵排、手机 2×2；真实/理想切换在画布底部；知识三列、判断选项与下一节位置对应参考。
